# 📄 Pro Resume & CV Architect

Chatbot berbasis AI yang dirancang untuk membantu pengguna menyusun resume profesional yang dipersonalisasi dan **ATS-Friendly** (Applicant Tracking System).

## ✨ Fitur Utama
- **Job Matching:** Menyesuaikan pengalaman user dengan kriteria loker.
- **ATS Optimization:** Menggunakan kata kunci strategis agar lolos seleksi sistem.
- **Instant Draft:** Menghasilkan format resume yang rapi dalam hitungan detik.

## 🛠️ Teknologi
- **Python**
- **Streamlit** (UI Framework)
- **Google Gemini Pro API** (LLM Model)

## 🚀 Cara Menjalankan
1. Clone repositori ini.
2. Install library: `pip install -r requirements.txt`.
3. Jalankan aplikasi: `streamlit run app.py`.
